# construction-project-analytics
Construction Project Performance Analytics &amp; Decision Support System using Python, SQL and Power BI

A data-driven construction project analytics system developed using **Python, MySQL, Power BI, Excel/CSV** to monitor project cost, schedule, productivity, quality, materials, and equipment performance.
![image alt](https://github.com/Sukchand30/construction-project-analytics/blob/23c6367b634e9b94dd549973c5f7cb78521f551b/dashboard.png)
---

## 📌 Project Overview

The **Construction Project Performance Analytics & Decision Support System** transforms construction project data into meaningful KPIs and interactive dashboards for project monitoring and decision-making.

The project analyses:

- 💰 Cost performance
- 📅 Schedule and progress
- 📊 Earned Value Management (EVM)
- 👷 Labour productivity
- 🧱 Material wastage
- ✅ Quality performance
- 🚜 Equipment utilization
- ⚠️ Activity delays

> **Dataset:** Simulated construction project dataset created for analytical and portfolio purposes.

## 🎯 Objectives

1. Monitor construction project cost and budget performance.
2. Compare planned and actual project progress.
3. Identify delayed and underperforming activities.
4. Calculate CPI and SPI using Earned Value Management.
5. Analyse labour productivity.
6. Monitor material consumption and wastage.
7. Evaluate quality inspections and rework costs.
8. Analyse equipment operating hours and utilization.
9. Develop an interactive Power BI dashboard for project decision support.
